# Архитектурное решение по логированию
## Мотивация:
Сейчас мы знаем о сбоях только по отзывам клиентов — нужно отслеживать крайне внимательно логи уровня ERROR и FATAL, чтобы как можно быстрее исправлять сбои, и как можно меньше клиентов сталкивалось с ошибками. Это позволит снизить количество обращений в поддержку и повысить доверие клиентов, а также упростить расследование и разрешение проблем.

## Предлагаемое решение:

1. Нам необходимо внедрить логи в Shop, MES и CRM. 
2. Используем log4j для Java, Serilog для C#, собираем централизованно в Loki. 
3. Визуализируем в Grafana, что даст нам единое окно наблюдаемости для всех метрик, логов и трейсинга.

## Список необходимых логов:

## Анализ логов:

1. Необходим алертинг для кейсов, когда происходит сбой модуля подсчета стоимости. Алерт направляется в Slack/email технической поддержки для немедленного реагирования.
2. Ежедневный отчёт о рисковых заказах. Система формирует email-отчёт на основе логов:
   
   - Заказы, которые остаются в статусе SUBMITTED более 4 часов.
   - Сообщения, которые не получили подтверждения (не дошли до MES или CRM).
   - Некорректные переходы статусов (например, SHIPPED → SUBMITTED).
   - Этот отчёт получают менеджеры, чтобы они могли вручную проверить подозрительные кейсы.

## Безопасность:
1. Анонимизируем значения:
   - [anon_user_id], [anon_manager_id] — это либо хеш (SHA-256(user_id)), либо ID сессионного уровня (session_user_1).
   - [masked_error_code] — только код или тип, без текстового stacktrace.
   - [provider_code] — чтобы не указывать напрямую имя службы доставки.
2. Ограничиваем доступ к логам только для разработчиков, поддержки и девопсов.

## Последовательность реализации логирования и трейсинга:
1. Логирование MES — самый проблемный компонент, а логи позволят реагировать до жалоб
2. Трейсинг Shop + CRM — прост в реализации, сможем отслеживать зависшие заказы.
3. Трейсинг MES — стоит дорого, но поможет делать анализ расчетов и производства
4. Логирование Shop + CRM — можем использовать как базу для отчетности и анализа проблем UX.
